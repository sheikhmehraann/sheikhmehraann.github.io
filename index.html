I'm Sheikh Mehraan (also online as SheikhMehraan, sheikhmehraann, sheikh mehraann, sheikhmehraan, Mehraann, and mehraann19), a developer from Kashmir. I work on low-level Android internals, MediaTek bootloaders, custom recoveries, kernel builds, and firmware tools, mostly around the Infinix GT 20 Pro (X6871 / MediaTek Dimensity 8200 Ultimate / MT6895).

Official accounts

GitHub: github.com/sheikhmehraann - Telegram: @mehraann19 - SourceForge: mehraann19 - Email: mehraann.19@gmail.com

Bootloader, kernel, and recovery

  • Fenrir-X6871 (GitHub) - MediaTek LittleKernel (LK) payload injector and AVB/verified boot patcher for the Infinix GT 20 Pro (X6871) on Android 16.
  • Renkai-X6871 (GitHub) - Patched LittleKernel (lk) and bootloader images for X6871 on XOS 14 and XOS 15 (Android 14 and 15).
  • X6871-Recovery-Project (GitHub) - Multi-recovery Android 16 (Linux 6.12 GKI) vendor_boot device tree and GitHub Actions builder for Infinix GT 20 Pro (TWRP, YARP, OrangeFox, AERA, PBRP, SHRP) with Trustonic decryption, touch, and haptics patches.
  • gki-5.10-kernel-builder (GitHub) - GitHub Actions workflow that builds Android GKI 5.10.270 with APatch root and packages an AnyKernel3 zip.

Firmware, OTA, and flashing tools

  • Newbies-Flasher (GitHub) - Zero-dependency Python GUI and CLI that packages raw, Android sparse, or zstd partition images into recovery-flashable zips on Windows, Linux, macOS, and Termux, with lptools dynamic partition and AVB 2.0 vbmeta support.
  • Transsion-Firmware-Toolkit (GitHub) - CLI and GitHub Actions scripts for probing, extracting, repacking (.tar.zst), and flashing Transsion (Infinix, Tecno, itel) OTAs.
  • transsion-flashable-builder (GitHub) - Builds A/B recovery-flashable zips from Transsion stock firmware dumps using lptools and zstd.

Android mods and utilities

  • OnePeek (GitHub) - Small libxposed (API 102 / LSPosed) module for Google One that queries Play Billing offers and free trials and shows the raw pricing phases.
  • IOS-Emoji-Font (GitHub) - Magisk, KernelSU, and APatch module replacing Android system fonts with Apple SF Pro and iOS emoji, with metric patch tools for Indian and RTL writing systems.
  • gofile-fast-link-transfer (GitHub) - Transfers files from Google Drive, SourceForge, MediaFire, Dropbox, or direct URLs straight to GoFile using multi-connection downloads and curl.
  • WinMemoryCleaner (GitHub) - Modified fork of Igor Mundstein's WinMemoryCleaner with extra Windows tweaks, minimize-to-tray behavior, and a compact settings layout.
  • Antigravity-Jailbreak (GitHub) - System prompt profiles and a Python/Batch switcher for Google Antigravity AGENTS.md files.

What I use

Python, C, C++, ARM64 assembly, Kotlin, Makefile, Shell, Batch, and C#. Most of the Android work uses LittleKernel, AVB/VBMeta, vendor_boot, lptools, payload.bin, AnyKernel3, TWRP/OrangeFox, Magisk/KernelSU/APatch, LSPosed, and GitHub Actions.
